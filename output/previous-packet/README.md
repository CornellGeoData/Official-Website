# Sponsorship packet, 2026-2027

`build_packet.py` creates a six-page US Letter PDF: cover, team, sponsorship
impact, sponsorship levels, projects, and contact. The original cover is retained
as an image. Pages 2–6 use native PDF text and graphics, with the original boards'
black background, white border, and photographs.

The shared grid has 36pt content margins, 36pt Arial Black main headings, 21pt
section headings, Source Serif body text at 14.5pt with 19pt leading, and 10.5pt
captions. Projects use three evenly spaced image/text rows. Contact information
is grouped beside the Business Lead's portrait, followed by website/social links
and a sponsorship QR code. Page numbers, PDF bookmarks, and clickable contact
links are generated by the script.

`assets/` contains the original cover and cropped material from the supplied
boards, including the badges and three project images. The larger board crops
are retained as references; they are not page backgrounds in the current build.
The team photo, fieldwork photo, logo, and contact portrait come from `public/`.

Build on macOS with Pillow, ReportLab, the site's Source Serif fonts, and the
system Arial Black font. Poppler supplies `pdftoppm` for visual review:

```sh
python3 docs/sponsorship/build_packet.py
mkdir -p /tmp/geodata-sponsorship-preview
pdftoppm -png -scale-to 1800 output/pdf/Cornell-GeoData-Sponsorship-2026-2027.pdf /tmp/geodata-sponsorship-preview/page
```

Review all six rendered pages at readable size, particularly line breaks,
caption spacing, photo crops, and contact details. After review, copy the PDF to
`public/sponsorship/packet.pdf` and convert `page-1.png` through `page-6.png` to
WebP previews named `public/sponsorship/page-01.webp` through `page-06.webp`.
Keep `PACKET_PAGE_COUNT` in `src/pages/sponsors/SponsorsPage.tsx` aligned with the
PDF. Run `npm run dev` and check `#/sponsors`: all pages, navigation, Fullscreen,
and the PDF download. `npm run build` refreshes the production files in `dist/`.

Sponsorship amounts and benefits match `TIERS` in `src/data/content.ts` as of
November 5, 2026. Update both when the program changes. The student count is
calculated from the roster at build time. Project status reflects the supplied
boards and current project posts: the hexapod is in development and the buoy is
being refitted. No deployment or fundraising outcome is implied by those images.
The contact page uses the current Business Lead's public roster entry and portrait.

The previous packet remains available in Git history.
