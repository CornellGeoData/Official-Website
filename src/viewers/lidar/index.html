One finger rotates. Pinch to zoom; move two fingers to pan. Tap a point to inspect it.

NYS Central Finger Lakes 2020 survey.

All 11,400,976 source points were semantically segmented using 3dsem with Utonia weights fine-tuned for aerial LiDAR.

The semantic segmentation was not domain generalized, so some visible classification errors remain; future post-processing and other refinements can improve accuracy.
